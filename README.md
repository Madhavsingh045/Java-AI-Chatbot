# 🤖 AI Chatbot Using Java

## 📌 Project Overview
This project is a desktop-based AI Chatbot developed using Java and Java Swing. It interacts with users in real time and provides answers to frequently asked questions using rule-based logic and basic Natural Language Processing (NLP) techniques.

## ✨ Features
- Interactive graphical user interface (GUI)
- Real-time user and chatbot interaction
- Rule-based question answering
- Basic NLP text preprocessing
- FAQ-based knowledge system
- Chat history saved in a text file
- Clear Chat functionality

## 🛠️ Technologies Used
- Java
- Java Swing
- AWT
- File Handling
- Basic NLP techniques

## ▶️ How to Run
1. Install Java JDK.
2. Open the project folder in VS Code.
3. Open the terminal inside the `src` folder.
4. Compile the program:
   `javac ChatbotGUI.java`
5. Run the chatbot:
   `java ChatbotGUI`
